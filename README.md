# Portfolio UX di Nicole Alilo Mbo

Sito personale di Nicole Alilo Mbo, UX Designer, realizzato come progetto finale in HTML, CSS e Sass.

**Sito online:** https://nicolealilombo97.github.io/portfolio/

## Pagine

- **Home**: presentazione, sezione "Chi sono" e progetti con i case study
- **CV**: curriculum scritto in HTML
- **Contatti**: modulo di contatto con campi obbligatori

## Tecnologie

- HTML5 e CSS3
- Sass (SCSS)
- Bootstrap 5
- Flexbox e CSS Grid
- Formspree per l'invio del modulo
- GitHub Pages per la pubblicazione

## Struttura del progetto

- `index.html`, `cv.html`, `contatti.html`: le tre pagine
- `scss/style.scss`: stili in Sass
- `css/style.css`: stili compilati
- `img/`: immagini e copertine dei progetti
- `pdf/`: case study in PDF

## Compilare gli stili

Dopo aver installato Sass (`npm install -g sass`):

`sass scss/style.scss css/style.css`
